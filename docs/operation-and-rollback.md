# 使用、配置和分层回滚

## 日常使用

1. 从原书库点击 KUAL，直接打开本机主页。保持手动启动。
2. 已配对耳机取出后自动连接；不要重复点恢复连接。录音后保存、回放，共用持续会话。
3. “书库／看书”返回原系统，可保留会话；“退出主页”结束服务并恢复原生音频。这两个按钮含义不同。
4. 本地 MP3/WAV 放入 `/mnt/us/kt3-home/music`，可放一层子文件夹。专有加密音乐文件不支持。
5. 日历点选日期后编辑并保存备忘。数据不是上传到云端。

## DeepSeek 以后配置

参考 [空配置](../examples/deepseek.example.json)，仅在申请 API Key 后，在自己的设备上创建 `/var/local/kt3-home/deepseek.json`；root 所有，目录 700、文件 600。不在 USB 可见目录存 Key，不粘贴到公开问题单。

模型按当前 API 文档配置；示例默认 `deepseek-flash`。点击主页“检查配置”即可重新读取，不需要重启。真实 API 调用尚未验收，服务端模型名称和计费规则可能变化。

当前实现固定官方 HTTPS 地址，不跟随重定向、不自动重试；未配置时拒绝发送。回答留在服务内存，输入草稿在浏览器本地；“新对话”丢弃迟到回答，但不能撤回远端已发生的计费。

## 回滚层级

| 层级 | 入口 | 影响 |
|---|---|---|
| 正常退出 | 页面“退出主页” | 停止会话，恢复原生音频，保留代码和用户数据 |
| 恢复上一版主页 | 设置“回滚旧版主页” | 校验本机备份、有序退出、恢复此次更新前代码 |
| KUAL 回原菜单 | 创建 `USE_KUAL_MENU` 标记 | 不再直接进入主页，不删除录音 |
| 撤销离线入口 | 本机保存的离线入口回滚脚本 | 恢复旧入口，旧入口可能重新要求 Wi-Fi |
| 撤销固定权限辅助 | 本机安装时的撤销脚本 | 撤销新增固定提权入口，需先结束会话 |
| 撤销 USB root | 本机 `/opt/kt3-root/rollback.sh` | 按安装备份撤销自定义 SSH 持久化 |

上述是**已改造设备**的恢复说明，不是要求新设备先创建这些文件。各回滚脚本与版本备份配套，不能随意混用。项目私有安装记录保留完整备份；公开仓库不含私人设备恢复镜像。

回滚前先正常退出，不在录音中强杀服务；校验 SHA256，检查会话锁和恢复失败标记。只在必要的安装阶段短暂挂载真实根分区为可写，完成后确认 `/dev/root` 只读。不删除书籍、录音和配对资料来解决服务状态问题。

## 异常快速定位

- 主页打不开但书库正常：检查固定入口、手动服务、回环探针、应用注册和页面上下文。
- 显示双工但按钮无响应：对照触摸 input、页面 pointer、HTTP 请求与 worker 事件，不能直接重连蓝牙。
- 书库十秒卡顿：先检查只读 BTFD 查询响应，不把整个系统服务 SIGSTOP 当作长期方案。
- 耳机入盒后没有回连：检查等待状态、目标地址缓存、控制器错误及恢复保护标记，不盲目连续重启。
- 短按电源无效：核对 `preventScreenSaver` 所有权，区分屏保和内核挂起。
